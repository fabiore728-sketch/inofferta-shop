# InOfferta.shop

Progetto Next.js/TypeScript per InOfferta.shop.

## Regola dati
Questo progetto NON contiene prodotti demo, prezzi inventati, recensioni inventate, Partita IVA inventata, indirizzi inventati o dati societari inventati.

Il catalogo è volutamente vuoto finché non vengono inseriti dati reali.

## Stato
Nessun checkout, pagamento, ordine o API commerciale è attivo.

## Avvio
Richiede Node.js 18.17+.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
